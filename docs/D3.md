# D3. Use Case Diagram

## Gambaran Umum

Use case diagram ini menggambarkan seluruh fitur CareerUp dari sisi aktor dan fungsinya. Setiap use case mewakili satu kemampuan yang bisa dilakukan oleh aktor di dalam sistem.

**Aktor:**
- **Job Seeker** — pengguna yang belajar, mengeksplorasi pekerjaan, dan mengerjakan simulasi.
- **Admin CareerUp** — pengelola yang membuat dan memelihara konten platform.

**Modul yang terwakili:**
Auth & Profile, Job Explorer, Learning, Simulation, Feedback & Progress, Content Management.

## Daftar Use Case

### Job Seeker

| Use Case | Modul | Deskripsi |
|---|---|---|
| Register | Auth & Profile | Membuat akun baru di CareerUp. |
| Login | Auth & Profile | Masuk ke sistem. Semua use case lain mensyaratkan login. |
| Set Target Job | Auth & Profile | Menetapkan pekerjaan target di profil. |
| Browse Jobs | Job Explorer | Melihat dan mencari daftar pekerjaan yang tersedia. |
| View Required Skills | Job Explorer | Melihat skill yang dibutuhkan untuk pekerjaan target. |
| View Learning Roadmap | Job Explorer | Melihat roadmap belajar: skill yang perlu disiapkan dan simulasi yang tersedia. |
| Learn Skill Material | Learning | Mempelajari materi singkat untuk skill tertentu. |
| Do Interactive Practice | Learning | Mengerjakan latihan interaktif sebagai pemanasan sebelum simulasi. |
| Do Job Simulation | Simulation | Mengerjakan simulasi pekerjaan bertahap. Use case ini **include** Choose Scenario dan Submit Task Answers. |
| View Feedback | Feedback & Progress | Melihat skor, status kesiapan, dan saran setelah simulasi. |
| Retry Simulation | Feedback & Progress | Mengulang simulasi jika status "Perlu Latihan Lagi". Hanya muncul pada kondisi tersebut (extend dari View Feedback). |
| View Progress | Feedback & Progress | Melihat riwayat hasil simulasi dan perkembangan per pekerjaan. |

### Admin CareerUp

| Use Case | Modul | Deskripsi |
|---|---|---|
| Login | Auth & Profile | Masuk sebagai Admin CareerUp. |
| Manage Jobs & Skills | Content Management | Menambah, mengubah, dan menghapus data pekerjaan serta skill yang dibutuhkan. |
| Manage Learning Materials | Content Management | Mengelola materi belajar dan latihan interaktif. |
| Manage Simulation Tasks | Content Management | Mengelola skenario simulasi, task, dan kunci jawaban. |
| Manage Feedback Rules | Content Management | Mengelola teks dan aturan feedback untuk setiap status kesiapan. |

## Hubungan Antar Use Case

### Include (<<include>>)
- **Do Job Simulation** selalu **include** **Choose Simulation Scenario** dan **Submit Task Answers**.
- **Submit Task Answers** selalu **include** **Generate Feedback**.

Artinya: ketika Job Seeker mengerjakan simulasi, langkah memilih skenario, mengirim jawaban, dan menghasilkan feedback terjadi secara otomatis sebagai bagian dari alur.

### Extend (<<extend>>)
- **Retry Simulation** **extend** **View Feedback**.

Artinya: Retry Simulation hanya terjadi jika kondisi terpenuhi — yaitu status hasil simulasi adalah "Perlu Latihan Lagi". Jika status "Siap" atau "Hampir Siap", Retry tidak muncul.

## Catatan

- Semua use case selain **Register** dan **Login** mensyaratkan pengguna sudah login (dicatat dalam use case diagram sebagai catatan global).
- Nama aktor dan modul sesuai dengan yang didefinisikan di [D1](D1.md) dan [D2](D2.md).
- Use case **Retry Simulation** sesuai dengan alur S3 di [D4](D4.md).
- Fungsi **`evaluate_simulation`** digunakan di dalam use case **Generate Feedback** (dijelaskan lebih detail di [D7](D7.md)).
